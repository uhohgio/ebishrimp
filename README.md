# ✨🦐Krill Yourself🦐✨  
 A video game by team ebi shrimp

### The Team:

Gio Ehrig, Erica Lee, Ian Gower, Jose Garcia, Liam Carter, Cameron Cobb

### The TL;DR:

“[*Who’s Your Daddy*](https://youtu.be/IH607hMeFM4?si=MrnuwKf1r503cLBb) except you’re a group of shrimp who try to find different ways to cook themselves.” \- Gio

### Description

Originally created as a school project, Krill Yourself is a level-based comedy game where you control a growing group of shrimp and try to cook them all before time runs out. **You are a shrimp troupe and have one objective, to krill yourself. Don’t be shell-shocked, the game isn’t entirely shrimpossible. Cook the entire troupe to win\!*

As you play, the game increases in difficulty as more obstacles arise. Do you have what it takes to be 5-star chef?

### The Shrimple Core Gameplay Loop

Players start with a base troupe of shrimp. Periodically, more shrimp are “tossed” into the scene. The shrimp troupe is controlled collectively in a swarm, so one input source moves the whole crew. If there are too many shrimp left uncooked, the player loses the game because of the Crustacean Devastation.
